# 安裝島輝

島輝是免費的注音輸入法，Windows 和 Mac 都能用。這一頁一步一步說明怎麼裝、裝好後怎麼開始打字、遇到問題怎麼辦，以及怎麼移除。不需要懂程式。

## Windows

適用：64 位元的 Windows 10、11。

1. **下載安裝檔**：按這裡 → **[DaoHui-Setup.exe](https://github.com/TimLin-1231/daohui-weasel/releases/latest/download/DaoHui-Setup.exe)**（約 17 MB）。
   - 瀏覽器如果說「這個檔案不常被下載」，選「保留」。
2. **打開下載的檔案**（在瀏覽器的下載清單裡點它，或到「下載」資料夾雙擊）。
3. **如果出現藍色的「Windows 已保護您的電腦」**：按「**其他資訊**」，再按「**仍要執行**」。
   這是因為島輝沒有買微軟的程式碼簽章，Windows 不認得發行者，不是病毒。
4. **「是否允許這個 App 變更您的裝置？」**：按「**是**」。輸入法要裝進系統，所以需要這個權限。
5. **等它裝完**（約 10 秒），會看到「島輝已經安裝好了」。
   - 「**下載語言模型**」預設是勾的：按「完成」後會打開「島輝設定」自動下載（約 410 MB）。下載時可以照常打字，下載完會自動套用。語言模型讓整句選字更準確，建議下載。
6. 按「**完成**」。

裝好後島輝就是你的預設輸入法，不用重新開機。**已經開著的程式要關掉再打開**，才會用到島輝。

## Mac

適用：macOS 13（Ventura）以上，Apple 晶片（M1、M2…）和 Intel 的 Mac 都可以。

1. **打開「終端機」**：按 <kbd>⌘</kbd>＋<kbd>空白鍵</kbd> 打開 Spotlight，輸入「**終端機**」（英文系統是 Terminal），按 <kbd>return</kbd>。
2. **複製下面這一行**（游標移到框框右上角，按複製圖示），**貼到終端機裡**（<kbd>⌘</kbd>＋<kbd>V</kbd>），按 <kbd>return</kbd>：

   ```bash
   curl -fsSL https://raw.githubusercontent.com/TimLin-1231/rime-asus-zhuyin/main/install/mac.sh | bash
   ```

3. **等它跑完**：它會下載島輝（約 26 MB）和語言模型（約 410 MB），看網速大約 1 到 5 分鐘。最後出現「**✔ 島輝裝好了**」就完成了，可以關掉終端機。

不用輸入密碼，也不會跳出「無法打開，因為無法驗證開發者」的警告。裝好後會自動切換到島輝，螢幕右上角選單列的輸入法圖示會變成「島」。

> 為什麼要用終端機？島輝沒有付 Apple 每年 99 美元的開發者簽章，從瀏覽器下載的安裝檔會被 macOS 擋下來，要到「系統設定」裡一層一層允許。用這一行指令下載就不會被擋，也一次把語言模型裝好。這一行做的事情都寫在 [install/mac.sh](../install/mac.sh) 裡，可以先打開來看。

如果你比較想用一般的安裝檔：到 [Mac 版的下載頁](https://github.com/TimLin-1231/daohui-squirrel/releases) 下載最新的 `DaoHui-*.pkg`，打開一次被擋下來後，到「系統設定 › 隱私權與安全性」按「強制打開」並輸入密碼，再照安裝程式的步驟裝。這樣裝不會有語言模型，之後還是要貼上面那一行補上。

## 開始打字

| 想做的事 | 按鍵 |
|---|---|
| 切換到島輝或別的輸入法 | Windows：<kbd>Windows 鍵</kbd>＋<kbd>空白鍵</kbd>；Mac：<kbd>🌐</kbd>（fn）或 <kbd>Control</kbd>＋<kbd>空白鍵</kbd> |
| 中文／英文切換 | 連按兩下 <kbd>Shift</kbd> |
| 送出打好的字 | <kbd>Enter</kbd>（空白鍵是一聲） |
| 選字 | <kbd>↓</kbd> 打開清單，按數字選；清單最後一列是你打的注音本身 |
| 改句子中間的字 | <kbd>←</kbd>／<kbd>→</kbd> 移到那個字，按 <kbd>↓</kbd> 選 |
| 忘記學錯的字 | 在清單裡反白那個字，按 <kbd>Shift</kbd>＋<kbd>Delete</kbd>（Mac：<kbd>Shift</kbd>＋<kbd>fn</kbd>＋<kbd>delete</kbd>） |
| AI 修正整句的錯字（選用） | 打字時按 <kbd>Ctrl</kbd>＋<kbd>R</kbd>。第一次要先下載 AI 模型：Windows 在「島輝設定 › 模型」，Mac 在輸入法選單的「下載 AI 修正模型」 |

所有功能的說明在 [README 的功能速查](../README.md#功能速查)。

## 更新

- **Windows**：有新版時會跳出通知，按「安裝更新」即可，之後的更新不會再問任何問題。也可以從開始選單的「島輝輸入法 › 【島輝】檢查新版本」手動檢查。
- **Mac**：在背景自動更新，不用做任何事（會在你沒有打字的時候換成新版）。要立刻更新，再貼一次上面那一行指令。

你學到的字詞和設定在更新後都會保留。

## 遇到問題

**Windows：Microsoft Defender 說找到威脅，把安裝檔刪掉了**
新的安裝檔偶爾會被 Defender 的自動判斷誤認（島輝已經回報給微軟處理）。可以到「Windows 安全性 › 病毒與威脅防護 › 保護歷程記錄」，找到島輝的安裝檔，確認名稱是 `DaoHui-Setup.exe` 或 `daohui-*-installer.exe` 後選「還原」。不放心的話，等幾天微軟更新判斷後再下載。

**Windows：按 Windows 鍵＋空白鍵 看不到島輝**
到「設定 › 時間與語言 › 語言與地區 › 中文（繁體，台灣） › 語言選項 › 新增鍵盤」，選「島輝」。

**Windows：語言模型沒下載完**
從開始選單打開「**島輝設定**」，到「**模型**」頁按「**繼續下載**」，會從中斷的地方接著下載。

**Mac：選單列找不到島輝**
先登出再登入（或重新開機）。還是沒有的話，到「系統設定 › 鍵盤 › 輸入方式 › 編輯… › ＋ › 繁體中文」加入「島輝」。

**Mac：終端機顯示錯誤或下載中斷**
再貼一次同一行指令就好，它會從中斷的地方繼續。還是不行的話，把終端機的畫面截圖，到 [Issues](https://github.com/TimLin-1231/rime-asus-zhuyin/issues) 回報。

**Mac：Control＋空白鍵 被拿去切換輸入法**
macOS 預設用 Control＋空白鍵 切換輸入法，島輝收不到。用連按兩下 Shift 切中英文就好；想用 Control＋空白鍵 切中英文的話，到「系統設定 › 鍵盤 › 鍵盤快速鍵 › 輸入方式」把它關掉。

**Mac：Caps Lock 會切到英文輸入法**
這是 macOS 的設定：「系統設定 › 鍵盤 › 輸入方式 › 編輯…」裡關掉「使用大寫鎖定鍵切換『ABC』輸入方式」。

**打字變得不準、學到奇怪的字**
在選字清單裡反白那個字，按 Shift＋Delete 讓島輝忘記它。

## 移除

**Windows**：「設定 › 應用程式」找到「**島輝輸入法**」，按「解除安裝」（或從開始選單的「島輝輸入法 › 卸載島輝」）。

**Mac**：打開終端機，貼上這一行，按 return：

```bash
curl -fsSL https://raw.githubusercontent.com/TimLin-1231/rime-asus-zhuyin/main/install/mac.sh | bash -s -- --uninstall
```

移除後，你學到的字詞、設定和語言模型會留在電腦裡（Windows：`%APPDATA%\DaoHui`；Mac：`~/Library/DaoHui`），重新安裝時會自動接著用。確定不要的話，可以自己刪掉那個資料夾。
